# Genomic Analysis Scripts

This repository contains a collection of Python scripts designed for performing genomic analyses, including sequence comparison, alignment, and visualization of results.

## Scripts
### 1. sequences_identity_heatmap.py
Calculate the pairwise identity and generate a heatmap for a set of sequences.  **Prepare your set of sequences in a FASTA file.**  The script will output a heatmap image representing the pairwise sequence identity.
